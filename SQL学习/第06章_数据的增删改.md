SQL 分两大类（记住这两个词，后面常提到）：

- **DML（数据操作语言）**：改"表里的数据"——本章的 INSERT / UPDATE / DELETE，外加[第 7 章](第07章_查询基础.md)起的 SELECT；
- **DDL（数据定义语言）**：改"表本身的结构"——[第 5 章](第05章_建表_数据类型与约束.md)的 CREATE / ALTER / DROP。

> 运行 `scripts/02_school_schema.sql` 先把示例数据灌进去，本章在它基础上操作：
> ```bash
> $ psql -h localhost -U student_pg -d beginner_pg -f scripts/02_school_schema.sql
> ```

## 6.1 INSERT：插入数据

### 基本形式（显式列出列名——推荐的唯一姿势）

```sql
INSERT INTO school.students (student_no, name, gender, birth_date, city)
VALUES ('S2023016', '谢婷', 'F', DATE '2005-09-18', '厦门');
```

要点：

1. **列名清单和 VALUES 一一对应**（第 5 列对第 5 个值）；
2. 没出现的列取默认值：`student_id` 自增、`enrolled_on` 是今天；
3. 文本用**单引号** `'...'`，日期写成 `DATE '2005-09-18'`（或 `'2005-09-18'` 也行，PG 能自动识别），数字不用引号。

**永远显式写列名**。`INSERT INTO 表 VALUES (...)` 这种省略列名的写法依赖列顺序，表结构一变就全错——这是新手雷区。

### 一次插多行

```sql
INSERT INTO school.departments (dept_name) VALUES
    ('计算机科学与技术学院'),
    ('数学科学学院');
```

### 插入时返回结果：RETURNING（PG 特色，非常好用）

```sql
INSERT INTO school.students (student_no, name, gender)
VALUES ('S2023017', '高翔', 'M')
RETURNING student_id, student_no, name;

 student_id | student_no | name
------------+------------+------
         17 | S2023017   | 高翔
```

自增 id 到底分配了多少？`RETURNING` 当场告诉你，程序开发中极常用。

### 从其他表复制：INSERT ... SELECT

```sql
-- 把数学系（dept_id=2）的教师复制一份"讲师记录"到 teachers（演示用）
INSERT INTO school.teachers (name, title, hire_date, dept_id)
SELECT name || '(助教)', '助教', CURRENT_DATE, dept_id
FROM school.teachers WHERE dept_id = 2;
```

INSERT 的数据来源不必是 VALUES，可以是任意 SELECT（[第 7 章](第07章_查询基础.md)学全后回来重看这条例子）。

### 插入被拒绝时

[第 5 章](第05章_建表_数据类型与约束.md)的约束此刻全部上岗，最常见三类报错：

```text
ERROR: duplicate key value violates unique constraint ...      -- 学号重复了
ERROR: null value in column "name" violates not-null ...       -- 必填列没给值
ERROR: insert or update on table ... violates foreign key ...  -- 引用了不存在的 id
```

**处理原则**：报错的那一行没进库，其余照常。读懂 DETAIL 行，改数据再插。

### 冲突时怎么办：ON CONFLICT（进阶）

```sql
INSERT INTO school.students (student_no, name, gender)
VALUES ('S2023016', '谢婷婷', 'F')
ON CONFLICT (student_no) DO UPDATE SET name = EXCLUDED.name;
-- 学号已存在时不报错，改成"更新姓名"。EXCLUDED 指本次想插入的新值
```

这在"同步数据、批量导入去重"场景非常有用，先混个脸熟。

## 6.2 UPDATE：修改数据

### 基本形式（牢记三段式）

```sql
UPDATE school.students
SET city = '福州市'              -- SET：改哪些列、改成什么
WHERE student_no = 'S2023016';   -- WHERE：改哪些行
```

执行后 psql 返回 `UPDATE 1`——**被改的行数**。这个数字是你的安全仪表盘。

### 改多列、用表达式

```sql
UPDATE school.courses
SET credit = credit + 0.5,       -- 新旧值可以运算
    hours  = hours + 8
WHERE course_name = '数据结构';
```

### 基于其他表更新（先看语法，第 9 章后重看）

```sql
UPDATE school.enrollments e
SET score = 60
FROM school.students s
WHERE e.student_id = s.student_id
  AND s.student_no = 'S2023005'
  AND e.score < 60;
-- 给 S2023005 的不及格课程统一提到 60（补考通过的模拟）
```

### ⚠️ 最危险的一条命令

```sql
UPDATE school.students SET city = '北京';
-- 没有 WHERE！全表 15 行的 city 全变成"北京"。UPDATE 15 就是事故现场
```

**安全铁律（重申[第 0 章](第00章_学习准备.md)承诺的三招）：**

1. **先 SELECT 预览**：`SELECT * FROM school.students WHERE student_no = 'S2023016';` 确认 WHERE 命中的正是你想改的行；
2. **用事务包裹**：`BEGIN; UPDATE ...;` 看一眼结果，不对就 `ROLLBACK;`（[第 12 章](第12章_事务.md)之前可先记住这三步咒语）；
3. **看 UPDATE 后面的数字**：预期改 1 行却返回 `UPDATE 15`，立刻 `ROLLBACK`。

## 6.3 DELETE：删除数据

```sql
DELETE FROM school.students WHERE student_no = 'S2023016';
-- DELETE 1：删了 1 行
```

- 和 UPDATE 一样：**WHERE 决定删哪些行，没有 WHERE 删全表**；
- 删除学生的同时，他在 enrollments 里的选课记录会因 `ON DELETE CASCADE` **跟着自动删除**——[第 5 章](第05章_建表_数据类型与约束.md)设计的联动在保护一致性；
- 也有 `RETURNING`：`DELETE FROM ... WHERE ... RETURNING *;` 返回被删的行，用于留档确认。

### DELETE vs TRUNCATE

| | `DELETE FROM 表;` | `TRUNCATE 表;` |
|---|---|---|
| 速度 | 逐行删，大表慢 | 秒清，重置存储 |
| WHERE | 支持 | 不支持（只能全清） |
| 触发器/回收 | 逐行触发 | 整表操作 |
| 自增序列 | 继续 | 重置回 1 |

## 6.4 综合工作流示例：新学期来了一名插班生

```sql
BEGIN;                                                        -- 开事务，摔不坏
INSERT INTO school.students (student_no, name, gender, birth_date, city)
VALUES ('S2023016', '邓超群', 'M', DATE '2004-10-05', '福州')
RETURNING student_id;                                         -- 已有 15 名学生，这里返回 16

INSERT INTO school.enrollments (student_id, course_id)
VALUES (16, 1), (16, 3);                                      -- 选数据库原理、高数下
COMMIT;                                                       -- 两步一起生效
```

两步 INSERT 是一个整体：要么都成功，要么都消失（[第 12 章](第12章_事务.md)深挖原理）。

## 本章小结

- INSERT 显式写列名、多行 VALUES 批量插、`RETURNING` 拿回自增 id；
- UPDATE 三段式 `UPDATE 表 SET 列=值 WHERE 条件`，**没有 WHERE 就是全表事故**，先 SELECT 预览 + 事务包裹；
- DELETE 同样怕没 WHERE；外键 CASCADE 会让关联数据自动清理；
- 所有写入都被[第 5 章](第05章_建表_数据类型与约束.md)的约束实时拦截，报错是保护不是故障；
- 增删改动的只是数据，`\dt` 里表依旧，用 `scripts/03_reset_school.sql` 可随时一键还原练习数据。
