## 这是什么

一份**纯 Markdown** 的 PostgreSQL 系统教程，默认部署环境是 **Linux 服务器**（Ubuntu 为主线），配备**可以真跑起来的示例库**和**分章节的练习脚本**。

- 📖 **17 章正文**：数据库概念 → 安装部署 → psql/pgAdmin/dbx → 建库建表 → 增删改查 → JOIN/聚合/窗口函数 → 事务 → 索引优化 → 备份恢复 → 权限安全 → 综合项目
- 🗂 **4 篇附录**：术语表、**错误信息速查**（报错字典）、SQL 速查表、自测与面试题
- 🧪 **13 个脚本**：一键建库、示例数据、一键重置，以及 9 个"题目 + 参考答案"分段的练习文件
- ✅ **所有 SQL 脚本都在真实 PostgreSQL 实例上跑通验证过**，练习答案里的每个数字都核对过

**示例场景**：学生选课管理系统（5 张表、15 名学生、8 门课程、42 条选课记录），统一约定数据库 `beginner_pg`、用户 `student_pg`、模式 `school`。

## 适合谁 / 不适合谁

**适合你，如果**：

- 完全没用过数据库、没写过 SQL，甚至很少用命令行；
- 想把 PostgreSQL 装在一台 Linux 服务器上，从自己的电脑连过去用；
- 想系统学一遍而不是只背几条查询语句；
- 需要一份能随时查阅的手册（速查表 / 报错字典 / 术语表）。

**可能不适合你，如果**：

- 已经熟悉 MySQL 或其他关系型数据库——建议直接跳到 [第 5 章](第05章_建表_数据类型与约束.md) 之后；
- 想专攻**数据库内核、高可用集群、性能调优专家**级别——本教程是入门到实战，进阶方向在第 16 章末尾列出了路线，但不展开；
- 需要视频课程——本教程只是文字。

## 快速开始

### ① 在 Ubuntu 服务器上装 PostgreSQL 16

```bash
# 一键脚本（建议先 cat 看一遍再执行）
sudo ./scripts/00_install_ubuntu.sh

# 或者手动：添加 PGDG 官方源后安装
sudo apt install -y postgresql-16
```

详步骤与原理见 [第 2 章](第02章_安装与服务管理.md)。

### ② 创建学习用的用户、数据库和模式

```bash
# 管理员身份执行（Linux 的 postgres 用户默认不需要密码）
sudo -u postgres psql -f scripts/01_create_user_db.sql
```

创建内容：角色 `student_pg`、数据库 `beginner_pg`、模式 `school`。

### ③ 导入示例数据，开始学习

```bash
psql -h localhost -U student_pg -d beginner_pg -f scripts/02_school_schema.sql
psql -h localhost -U student_pg -d beginner_pg     # 进入 psql，从第 3 章开始
```

> 📌 **数据库在云服务器、你用自己的电脑操作？**
> 不要急着把 5432 端口开到公网，走 **SSH 隧道**更安全（详见 [第 2.6 节](第02章_安装与服务管理.md)）：用 Termius / Tabby 建一条本地转发 `127.0.0.1:15432 → 服务器 127.0.0.1:5432`，再用 dbx / pgAdmin 连上去。**服务器配置一行都不用改。**

## 练习怎么用

每个练习文件分两段：上半部分是**题目**，下半部分是**参考答案**（用大分隔线隔开）。推荐流程：

1. 自己在 psql 里把 SQL 敲一遍（**不要复制粘贴**，敲一遍的记忆效率高数倍）；
2. 卡住超过 10 分钟再看参考答案；
3. 增删改的练习会把数据改乱——任何时候运行 `scripts/03_reset_school.sql` 即可恢复初始数据。

> ⚠️ 全部脚本只作用于 `beginner_pg` 这一个练习库，不会碰服务器上的其他库。

## 约定与兼容性

- **PostgreSQL 16 及以上**为目标版本，**14 亦可运行全部脚本**；
- **Linux（Ubuntu 22.04 / 24.04）为主线**，macOS / Windows 的差异用 `> 🖥 系统差异` 提示框标注；
- **示例约定**：数据库 `beginner_pg`、用户 `student_pg`、模式 `school`；
- 命令行约定：`$ 命令` 表示在终端执行，`beginner_pg=>` 表示在 psql 内部执行，SQL 以分号结尾。

### 已知限制（如实说明）

- 附录 B 的报错原文抓取自 PostgreSQL 14，「`ERROR:` 那一行」跨版本稳定，但 `DETAIL` / `HINT` 的具体内容会随版本和数据变化；
- dbx / Termius / pgAdmin 的操作步骤按通用菜单命名描述（官方文档为 JS 渲染，无法逐字核对当前版本 UI 文案），实际菜单名可能略有出入；
- 尚未提供 Docker 一键实验环境，"搭环境"目前需要按 [第 2 章](第02章_安装与服务管理.md) 手动操作。
