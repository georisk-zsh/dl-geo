在正式接触 PostgreSQL 之前，这一章解决三件事：确认这份教程适合你、准备好工具、掌握"不把自己坑了"的基本功。

## 0.1 这份教程适合谁

适合**完全零基础**的读者，具体来说：

- 没用过数据库、没写过 SQL；
- 很少或从没用过命令行（终端）；
- 想系统学习 PostgreSQL，而不是只背几条查询语句。

如果你已经熟悉 MySQL 或其他数据库，可以跳过第 0、1 章，从[第 2 章](第02章_安装与服务管理.md)开始。

## 0.2 学习 PostgreSQL 需要哪些基础

**几乎不需要**，但下面几点有则更好：

| 基础 | 是否必需 | 说明 |
|---|---|---|
| 会开关机、装软件 | 必需 | 有电脑就行 |
| 英文 26 个字母、常见单词 | 必需 | SQL 关键词是英文（如 SELECT、WHERE），但总共就几十个词 |
| Excel 用过 | 不必需 | 用过更好，[第 1 章](第01章_数据库基础概念.md)会拿 Excel 做类比 |
| 编程经验 | 不必需 | SQL 不是传统意义的编程语言，语法接近英语句子 |

唯一真正的门槛是**动手**：每章的每条命令都要自己敲一遍。

## 0.3 数据库和 Excel 的区别

很多初学者第一个疑问："Excel 也能存学生名单，为什么还要数据库？"

| 场景 | Excel | 数据库（PostgreSQL） |
|---|---|---|
| 数据量 | 几万行就明显变卡 | 百万、亿级行照常工作 |
| 多人同时编辑 | 文件锁，A 改时 B 只能等 | 成百上千人同时读写，自动排队、加锁 |
| 误删恢复 | Ctrl+Z 有时不灵（保存关闭后就没救） | 有事务机制，删错了可以"撤销"；有备份机制 |
| 数据校验 | 靠人眼 | 可以规定"分数只能是 0~100"，违规数据根本写不进去 |
| 查询 | 筛选、VLOOKUP，条件一复杂就乱 | 一条 SQL 几十种条件随意组合 |
| 权限 | 整个文件谁拿到谁能改 | 可以精确到"某人只能看某几张表的某几列" |

一句话总结：**Excel 是"一张智能表格"，数据库是"一个管理数据的专职部门"**——本教程就是教你当这个部门的负责人。

## 0.4 数据库和普通文件的区别

用记事本（.txt）也能存数据，为什么不行？

1. **没有结构**：文件里 `张三,20,北京` 和 `李四, 21, 上海`（多个空格）对程序来说是两种东西，数据库则强制每列有固定类型和格式；
2. **没有查询能力**：想在文件里找"所有北京且年龄大于 20 的人"，你得自己写程序逐行扫描；数据库用一条 `SELECT` 搞定；
3. **没有并发控制**：两个程序同时写同一个文件，数据会互相覆盖；数据库保证不会；
4. **没有安全机制**：文件要么全给、要么全不给；数据库可以精确授权。

## 0.5 本教程使用的工具

| 工具 | 是什么 | 什么时候用 |
|---|---|---|
| **psql** | PostgreSQL 官方命令行客户端，安装数据库时自带 | 全教程主力工具，命令行是数据库工程师的"母语" |
| **pgAdmin** | PostgreSQL 官方图形化管理界面 | [第 3 章](第03章_psql与pgAdmin.md)入门，日常配合 psql 使用 |
| **Termius / Tabby** | SSH 终端工具（连接 Linux 服务器、传文件、建 SSH 隧道） | 第 2.6 节。数据库装在服务器上时，它是你操作服务器和数据库的入口 |
| **dbx** | 轻量级数据库 GUI（约 20MB，能管 90+ 种数据库） | 第 2.6 节。远程连库、看表结构、写 SQL，比 pgAdmin 更轻快 |

> 建议：**以 psql 为主**。面试和服务器排障时没有图形界面，命令行功夫才是真功夫；图形工具是在你懂原理之后提效用的。

## 0.6 Windows、macOS、Linux 命令的基本区别

本教程的**主线环境是 Linux**（数据库通常部署在 Linux 服务器上），遇到系统差异会这样标注：

> 🖥 **系统差异**
> - macOS：与 Linux 同属 Unix 体系，绝大多数命令相同；
> - Windows：使用 PowerShell（蓝色/黑色窗口里的"命令提示符"升级版），部分命令不同。

最常碰到的差异对照（先有印象即可，用到时回来查）：

| 操作 | Linux / macOS | Windows PowerShell |
|---|---|---|
| 查看当前目录 | `pwd` | `pwd` |
| 列出文件 | `ls` | `dir` 或 `ls` |
| 切换目录 | `cd 目录名` | `cd 目录名`（相同） |
| 查看文件内容 | `cat 文件名` | `cat 文件名` 或 `type 文件名` |
| 管理员权限 | 命令前加 `sudo` | 以管理员身份打开 PowerShell |
| 路径分隔符 | `/` | `\`（但多数工具也认 `/`） |
| 安装软件 | `apt install` / `dnf install` | 下载安装包双击 |

## 0.7 如何打开终端

**Linux（Ubuntu 桌面版）**：按 `Ctrl + Alt + T`；服务器版登录后直接就是终端。

**macOS**：`应用程序 → 实用工具 → 终端`（Terminal）；或按 `Command + 空格` 输入 `terminal` 回车。

**Windows**：开始菜单搜 `PowerShell`，点击打开（日常够用；需要管理员权限时右键"以管理员身份运行"）。

打开后你会看到类似这样的一行字加一个闪烁光标：

```text
me@my-server:~$
```

含义：`me` 是你的用户名，`my-server` 是机器名，`~` 是当前目录（家目录），`$` 表示等待你输入。

## 0.8 如何复制和执行命令

1. **复制**：在终端里选中文字即已复制（Linux 部分发行版需按 `Ctrl+Shift+C`；macOS 直接 `Command+C`）；
2. **粘贴**：Linux 按 `Ctrl+Shift+V`（或鼠标右键→粘贴；注意不是 `Ctrl+V`！），macOS `Command+V`，Windows PowerShell 鼠标右键；
3. **执行**：敲完（或粘贴完）命令后按 **回车（Enter）** 才会运行；
4. **中断一个正在跑的命令**：按 `Ctrl + C`；
5. **命令历史**：按 **上箭头 ↑** 可翻出之前敲过的命令——这是最实用的省力键。

> ⚠️ 教程中形如 `$ sudo apt update` 的行，`$` 是提示符**不需要你输入**，你只敲它后面的部分。

## 0.9 教程中的代码、命令、输出分别代表什么

全书用三种"框"区分内容：

**① 你要敲的命令**（终端里，提示符 `$`）：

```bash
$ ls
```

**② psql 里要敲的 SQL**（提示符 `beginner_pg=>`）：

```sql
BEGINNER_PG=> SELECT 1;
```

**③ 电脑显示的输出**（不需要你敲，用来对照自己的结果）：

```text
 ?column?
──────────
        1
(1 行记录)
```

> psql 里每条 SQL 以**分号 `;` 结尾**才执行。初学者最常见的问题是"敲了回车没反应"——其实是忘了分号，psql 在等你继续输入，此时补一个 `;` 再回车即可。

## 0.10 如何避免误执行删除命令（必读！）

数据库领域真正的危险操作只有几类，从第一天就养成防御习惯：

**终端层（Linux）：**

- `rm -rf /某目录`：递归强制删除，**没有回收站**。执行前默念一遍路径，确认没有多余的空格；
- 删除前先"预演"：`ls /要删的路径` 先看一眼里面是什么，再换成 `rm -rf`。

**数据库层：**

- `DROP DATABASE` / `DROP TABLE`：整库、整表瞬间消失；
- `UPDATE` / `DELETE` **不带 WHERE 条件**：全表数据被改/被删——这是新手翻车率最高的地方；
- 防御三招：
  1. **先 SELECT 再改**：任何 UPDATE/DELETE 之前，先用同样条件的 `SELECT * FROM 表 WHERE 条件;` 看看会命中哪些行；
  2. **用事务包住**：`BEGIN;` → 执行危险操作 → 确认无误 `COMMIT;`，后悔了 `ROLLBACK;`（[第 12 章](第12章_事务.md)详解）；
  3. **备份先行**：改重要数据前先备份（[第 14 章](第14章_备份与恢复.md)）。

**本书练习零风险承诺**：教程所有操作都在 `beginner_pg` 练习库中进行，就算全删光，运行 `scripts/03_reset_school.sql` 一键恢复。

## 本章小结

- 数据库解决的是 Excel/文件解决不了的**规模、并发、安全、校验**问题；
- 本教程 Linux 为主、psql 为主，系统差异会有提示框；
- 终端粘贴是 `Ctrl+Shift+V`（Linux），SQL 要以分号结尾；
- 危险操作三板斧：先 SELECT、用事务、先备份。
